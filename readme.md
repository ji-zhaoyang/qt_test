## 源码阅读顺序指南

建议按下面顺序看，效果最好，能最快建立整体认知。

### 1. 先看启动入口
从最上层开始：

- main.cpp
- mainwindow.cpp
- mainwindow.h

你要先回答这几个问题：
- 应用启动后创建了哪些页面？
- 页面切换是怎么实现的？
- 主窗口和顶部导航是怎么连起来的？

这一步的目标是搞清楚“整个应用长什么样”。

---

### 2. 再看总控器
重点看：

- app_controller.cpp
- app_controller.h

这里是整个项目的“大脑”：
- 初始化数据库
- 创建协调器
- 建立 TCP 连接
- 连接各个模块的信号

如果你只看一层，建议先从这里入手，因为它串起了整个系统。

---

### 3. 看页面与协调器的关系
接着看三个核心协调器：

- home_coordinator.cpp
- history_coordinator.cpp
- settings_coordinator.cpp

它们的作用是：
- 把页面上的操作转成 TCP 请求
- 把设备返回的数据更新到界面

建议阅读顺序是：
1. HomeCoordinator：首页最核心
2. SettingsCoordinator：配置项最多
3. HistoryCoordinator：状态流转和历史记录逻辑较独立

---

### 4. 看页面实现
然后再进入各页面：

- home
- history
- settings

重点看页面类的信号定义和更新接口，例如：
- 页面如何发出动作请求
- 页面如何接收协调器更新的数据
- 页面自身是否有较复杂的 UI 逻辑

这一步可以帮助你理解“界面是如何被驱动的”。

---

### 5. 看网络通信层
重点看：

- network

其中最关键的是：
- tcp_manager.cpp
- tcp_manager.h

这里是和设备服务端交互的核心。
你要重点看：
- 连接建立
- 协议包解析
- 各种指令发送
- 各类回包信号发出

如果你想理解“页面上的操作为什么会有反应”，这里一定要看。

---

### 6. 看数据库与历史逻辑
再看：

- database
- repositories

重点是：
- 数据库初始化
- 历史记录如何落库
- 目标记录如何被更新和清理

这部分对理解“历史页为什么能记住目标”很重要。

---

### 7. 最后看前端网页部分
如果你对首页地图交互感兴趣，再看：

- 前端结构说明.md
- web

这里是 Qt 内嵌网页的前端逻辑，和 C++ 侧通过桥接通信。

---

## 推荐的最短阅读路径
如果你想尽快抓住项目主线，可以按这个顺序：

1. mainwindow.cpp
2. app_controller.cpp
3. home_coordinator.cpp
4. tcp_manager.cpp
5. settings_coordinator.cpp
6. history_coordinator.cpp
